# Plataforma de Orientación y Peticiones Ciudadanas

## Clase 46 - Inicio del Módulo 5

### Objetivo

Iniciar la planificación técnica de una plataforma orientada a la recepción, seguimiento y gestión de orientaciones y peticiones ciudadanas utilizando una metodología Scrumban y buenas prácticas de arquitectura de software.

### Estructura inicial

* src/
* public/
* docs/
* uploads/
* logs/
* tmp/

### Tecnologías previstas

* Node.js
* Express
* Git
* GitHub
* Variables de entorno (.env)
* JavaScript

### Buenas prácticas

* Protección de credenciales mediante `.gitignore`.
* Organización del código por carpetas.
* Documentación técnica desde el inicio del proyecto.
* Uso de control de versiones mediante Git.
* Desarrollo incremental utilizando ramas.
