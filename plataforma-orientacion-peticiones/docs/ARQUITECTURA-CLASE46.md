# Arquitectura inicial

## Objetivo

Diseñar una plataforma que permita registrar, consultar y hacer seguimiento a orientaciones y peticiones ciudadanas de forma organizada y segura.

## Componentes principales

### src

Contendrá la lógica de la aplicación.

### public

Almacenará los archivos públicos como HTML, CSS y JavaScript.

### docs

Guardará la documentación técnica del proyecto.

### uploads

Recibirá archivos cargados por los usuarios cuando sea necesario.

### logs

Almacenará registros de ejecución y diagnóstico.

### tmp

Contendrá archivos temporales utilizados por la aplicación.

## Principios de diseño

* Organización modular.
* Seguridad desde el inicio.
* Separación entre código, documentación y datos.
* Escalabilidad para futuras funcionalidades.
