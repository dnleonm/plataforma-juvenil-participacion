# Backlog inicial

## Historia 1

Como ciudadano quiero registrar una petición para que pueda ser atendida por la plataforma.

## Historia 2

Como administrador quiero consultar las solicitudes registradas para realizar seguimiento.

## Historia 3

Como usuario quiero conocer el estado de mi solicitud para mantenerme informado.

## Historia 4

Como administrador quiero mantener protegidas las credenciales y la información sensible del sistema.

## Prioridad

1. Crear la estructura del proyecto.
2. Configurar el entorno.
3. Implementar el servidor.
4. Crear las rutas iniciales.
5. Diseñar la interfaz.
6. Registrar peticiones.
7. Consultar información.
