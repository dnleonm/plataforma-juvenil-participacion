# Checklist jurídico para revisar derecho de petición

Antes de usar o enviar un derecho de petición, revisar:

- [x] La entidad destinataria está identificada.
- [x] El asunto es claro.
- [x] El solicitante está identificado.
- [x] Los hechos están escritos de forma respetuosa.
- [x] Los hechos no contienen afirmaciones falsas.
- [x] No hay acusaciones sin soporte.
- [x] La solicitud es concreta.
- [x] Se indica medio de notificación.
- [x] No se incluyen datos sensibles innecesarios.
- [x] No se incluyen datos reales en prácticas de clase.
- [x] El documento se reconoce como borrador editable.
- [x] Se advierte que debe revisarse antes de radicar.
- [x] Si se solicita información pública, se formula de manera clara.
- [x] Si se piden copias, se indica qué documentos se solicitan.
- [x] Si se trata de una ruta distinta, se orienta sin afirmar competencia definitiva.
