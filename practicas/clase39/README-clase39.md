# Clase 39 - Logs, Git e IA responsable

## Objetivo

Comprender el uso de logs para diagnóstico, Git para trazabilidad e IA como apoyo responsable.

## Archivos de práctica

* logs-demo.js
* telegram-log-demo.js
* bitacora-logs-git-ia-clase39.txt
* checklist-ia-segura-trazabilidad-clase39.txt

## Aprendizajes

* Un log ayuda a diagnosticar errores y comportamientos de una aplicación.
* Git permite mantener trazabilidad de los cambios realizados.
* La inteligencia artificial puede apoyar el aprendizaje y la resolución de problemas técnicos.
* Los tokens, claves y datos personales deben protegerse y no compartirse.
