# Clase 41 - Entorno de despliegue y primer levantamiento

## Objetivo

Comprender cómo levantar una aplicación Node.js utilizando variables de entorno y verificar su funcionamiento mediante rutas HTTP.

## Tecnologías utilizadas

* Node.js
* Express
* Dotenv

## Rutas verificadas

* /
* /saludo
* /estado
* /api/info

## Aprendizajes

* Uso de variables de entorno mediante .env.
* Protección de configuraciones mediante .gitignore.
* Levantamiento de aplicaciones Express.
* Verificación de disponibilidad mediante rutas HTTP.
