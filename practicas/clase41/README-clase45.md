# Clase 45 - Cierre integrador Semana 9

## Tema

Cierre operativo, seguridad, continuidad y control de versiones.

## Objetivo

Consolidar los conocimientos adquiridos durante la Semana 9 relacionados con servidores, estabilidad, monitoreo, documentación, Git y seguridad operativa.

## Actividades realizadas

* Verificación de rutas de la aplicación.
* Validación de variables de entorno.
* Comprobación de configuración de PM2.
* Revisión de seguridad mediante .gitignore.
* Protección de credenciales.
* Documentación técnica.
* Práctica conceptual de Git.
* Elaboración de bitácora y checklists.

## Aprendizajes principales

* Un servidor debe mantenerse estable y monitoreado.
* Las credenciales nunca deben publicarse.
* PM2 ayuda a mantener la continuidad operativa.
* Git permite controlar cambios y trabajar mediante ramas.
* La documentación facilita el mantenimiento de los proyectos.
